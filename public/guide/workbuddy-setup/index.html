WorkBuddy 自定义模型
怎么添加与使用？

使用本站积分时，请在 WorkBuddy 中选择接入本站接口的自定义模型。准备当前账户的 API Key 和可用模型 ID；客户端内置模型的积分与本站余额分开。

本页内容配置前准备接入步骤验证与排错如何查询消耗

配置前先准备什么？

登录会员中心，确认有可用积分；在“API 密钥”页面找到属于当前账户的个人密钥，在“模型中心”查看当前可用模型 ID 与倍率。支持的模型随上游变化，请以会员中心的实时列表为准。

Windows 用户可从会员中心下载针对当前账户的配置脚本，核对下载来源后运行，并按提示重启 WorkBuddy。不要使用他人的脚本，也不要在公开页面提交自己的密钥。

自定义模型接入步骤

  1. 打开会员中心左侧“WorkBuddy”配置教程，核对自己的客户端版本。
  2. 使用页面提供的接口地址、个人 API Key 与“模型中心”列出的准确模型 ID；不要选用客户端同名的内置模型。
  3. 按图文教程保存并重启 WorkBuddy，模型菜单选择刚添加的自定义模型，发送简短问题测试。
  4. 返回会员中心的“使用记录”检查调用、token 用量及实际消耗，核对控制台余额。

配置过程中的模型连通性测试也可能发起实际请求，并产生少量积分消耗。

积分不足与接口错误怎么排查？

为什么提示 WorkBuddy 官方账户积分不足？

先看模型菜单：首字母大写的 Auto 通常是客户端内置模型，本站自定义模型 ID 必须与会员中心一致。两套积分余额互不相通。

401、403、504 分别是什么意思？

  • 401：检查 API Key、接口地址与模型 ID。
  • 403：检查本站账户余额、套餐状态及模型是否可用。
  • 504：请求可能超时，稍后重试，并在使用记录中确认是否产生调用。

积分和 token 用量在哪里看？

登录后在控制台查看余额，在“使用记录”核对每次调用的输入、输出与消耗。本站按上游实际返回积分 1:1 记录，不按聊天次数固定扣费；展示的模型倍率不会再次乘到实际消耗上。详情见WorkBuddy 积分购买与消耗指南。
