WorkBuddy 积分如何购买、获取与领取？

在本站使用积分的流程是：获取本站兑换码或在会员中心选择充值套餐，登录后在“充值兑换”页兑换；账户余额可在控制台查看。兑换码首次登录或连接接口时激活，套餐有效期以订单说明为准。本站没有不经验证就能领取的免费积分入口，请勿相信所谓“免费刷积分”或索取 API 密钥的页面。

需要给 WorkBuddy 官方账号购买内置模型积分或会员权益，请前往 WorkBuddy 官方定价页了解官方渠道。本站的自定义模型积分与官方内置模型额度不是同一个余额。

WorkBuddy 积分价格与本站面值怎么区分？

本站采用 20 积分面值对应人民币 1 元 的展示口径。面值不等于商城订单的最终实付价格，更不等于 WorkBuddy 官方直充售价；实际购买价格、套餐及有效期请以结算订单为准。本站是独立服务，并非 WorkBuddy 官方直营充值渠道。

对比价格时，请同时看兑换后的积分数量、实付金额、有效期和可使用的自定义模型，而不是只看“单次请求多少钱”。

积分消耗与 token 怎么计算？

上游按请求实际用量计费，输入 token、输出 token、缓存和活动可能影响消耗。本站以上游返回的实际积分 1:1记录，不再重复乘模型列表展示的倍率。若上游返回 0 积分，该次请求不扣积分；一个任务可能触发多次请求，因此不能按聊天次数推算固定费用。

例如上游某次请求返回消耗 8.6 积分，本站记录消耗 8.6 积分。该数值只是计算示意，不代表任何模型固定单次价格。登录后在“使用记录”按模型、时间及请求次数核对消耗。

积分不够用或提示余额耗尽怎么办？

先确认 WorkBuddy 客户端选择的是通过本站接口添加的自定义模型。客户端首字母大写的 Auto 为内置模型时，它的额度与本站积分无关；本站自定义模型 ID 请以会员中心模型列表为准。其次检查本站账户余额和套餐状态，若需补充积分再选择兑换码或充值套餐。

添加模型的连通性测试也可能产生少量积分用量。想快速配置，请阅读自定义模型接入教程；想了解近期产品变化，可看有来源的模型资讯。
