## 合并规则与限制

- WorkBuddy、CodeBuddy（国内版和国际版）：保留其他 ID 的现有模型、当前供应商未选中的模型和模型附加字段；当前供应商相同 ID 更新。兼容数组和对象格式。平台 `www` / `api` 两个入口按同一供应商判断。
- 这两个客户端自身以 ID 为全局唯一标识；若选中 ID 已用于其他供应商，明确报冲突并停止安装，保留原文件。没有通过添加重复 ID 冒充配置成功。可取消冲突模型或选择支持供应商隔离的客户端。
- ZCode、DSH、Hermes：保留其他供应商、其他模型及附加属性，仅更新当前供应商的所选 ID；第三方服务按接口地址生成独立供应商标识及凭据名。ZCode 供应商显示 `WBAI微:36612995`，模型显示真实 ID。
- 多客户端安装遇到失败时自动恢复已修改配置，回传结果将已恢复项目显示为“已恢复原配置”。
- 实时模型目录保留上游真实 ID；`cn:` 别名复用已核实的名称和倍率说明。第三方模型不套用本平台倍率。
- TRAE 仅生成手动配置说明。浏览器无法扫描本机客户端；安装器依据现有配置目录判断，不等同于扫描所有可能的安装位置。
