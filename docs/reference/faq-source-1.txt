# 阿里云百炼 Token Plan 订阅概览页 · 官方FAQ（完整原文）
> 页面地址：[https://bailian.console.aliyun.com/cn-beijing/subscription/overview](https://bailian.console.aliyun.com/cn-beijing/subscription/overview)

**Q：Token Plan 提供哪些版本？**
A：Token Plan 提供个人版和团队版。个人版提供 Lite 套餐、Essential 套餐、Standard 套餐、Pro 套餐；团队版提供标准、高级、尊享不同档位席位。您可根据人员规模和使用强度选择合适的类型。

**Q：Token Plan 个人版和团队版有什么区别？**
A：Token Plan 团队版支持按席位购买、统一支付、集中管理成员和用量，适合多人协作的企业团队。对比个人版，团队版可以满足企业用户对数据安全隐私和并发性能的更高要求。

**Q：可以同时购买多个吗？**
A：每个实名认证主体不同版本（个人版、团队版）的 Token Plan 订阅限购一个。

**Q：套餐是否支持退订？**
A：个人版和团队版 Token Plan 均不支持退款。

**Q：抵扣规则是什么？**
A：Token Plan 使用 Credits 作为统一用量单位，来抵扣不同模型的消耗。实际消耗取决于每个任务中输入 Token、缓存 Token 和输出 Token 的组合。优先从订阅额度抵扣，额度用尽后从共享加油包抵扣，全部用尽后服务暂停。

**Q：Token Plan 额度限制是什么？**
A：个人版，团队版 token plan 均提供订阅月度限额，每个订阅月自动刷新，未用完不转结，不存在 5 小时/7 天的额度限制，可以畅快使用。

**Q：为什么订阅了 Token Plan，仍然产生了按量计费账单？**
A：这通常是因为 AI 工具中配置的是百炼通用 API Key（格式为 sk-xxxxx）和通用 Base URL，而非 Token Plan 专属凭证。系统会将此类调用识别为按量计费请求，不会抵扣订阅额度。请确保配置了订阅专属的 API Key 和 Base URL。

**Q：订阅额度是否能多人共用？**
A：Token Plan 团队版按席位独立分配额度，Token Plan 团队版 - 共享用量包可以跨席位共同抵扣。Token Plan 个人版套餐和团队版座席不支持多人共用。

**Q：什么是 Token Plan 专属 API Key 和 Base URL？**
A：Token Plan 提供套餐专属的 API Key（格式为 sk-sp-xxxxx）和 Base URL（[https://token-plan.cn-beijing.maas.aliyuncs.com/v1](https://token-plan.cn-beijing.maas.aliyuncs.com/v1)），用于在 AI 工具中接入模型服务并抵扣套餐额度。您可以在「我的订阅」页面中查看和复制。请注意：必须使用专属凭证，使用百炼通用 API Key 将无法抵扣套餐额度。

**Q：Token Plan 支持使用哪些模型，如何切换？**
A：Token Plan 支持套餐模型列表中的所有模型，包括千问系列及第三方优秀模型。完整的模型列表可在「我的订阅」页面查看。使用列表外的模型会返回错误。

**Q：Token Plan 支持哪些 AI 工具？**
A：Token Plan 兼容所有支持 OpenAI 或 Anthropic 接口协议的工具，包括但不限于 Qwen Code、Claude Code、OpenClaw、OpenCode 等。您可以在帮助文档中查看各工具的配置方法。

**Q：Token Plan 可以生成多个 API Key 吗？**
A：当前每个个人版套餐或团队版席位仅支持一个专属 API Key。如果密钥泄漏，可在「我的订阅」页面重置以生成新密钥，重置后原密钥立即失效。

**Q：如何查看套餐用量？**
A：在「我的订阅」页面可以刷新和查看用量消耗情况。

**Q：如何使用模型内置工具？**
A：Token Plan 支持在模型调用时通过 Response API 格式附带联网搜索、文搜图、图搜图、网页抓取、代码解释器等内置工具，直接在模型请求中启用即可，具体接入方式可参考产品的最佳实践。

**Q：附赠的 Harness 权益如何使用？**
A：Standard、Pro 套餐每月订阅会自动赠送一批百炼 Harness 服务的权益额度，无需单独申请或配置。您在 AgentStudio 或百炼应用服务中正常调用对应能力（联网搜索、图像生成、代码解释器、RAG、Memory、Managed Agent 等），系统会自动识别 Token Plan 订阅身份并优先抵扣附赠权益。具体权益项目和额度以「我的订阅」页面为准。Lite 套餐不含附赠 Harness 权益，如需使用可升级至 Standard 或 Pro，升级后按剩余天数折算获得对应权益。

**Q：附赠 Harness 权益的抵扣顺序是什么？**
A：先抵扣对应服务本身的免费额度（如各产品自带的试用/新用户额度），再抵扣 Token Plan 附赠的权益额度；权益额度用尽后，超出部分按对应服务的折扣价继续按量计费。

**Q：Harness 调用使用哪个 API Key？**
A：Harness 相关服务（联网搜索、图像生成、代码解释器、RAG、Memory、Managed Agent、Sandbox 等）使用百炼通用 API Key（格式为 sk-xxxxx）接入，Base URL 使用百炼标准接入地址。系统会自动识别账号下的 Token Plan 订阅并应用附赠权益，无需切换到 Token Plan 专属凭证。Token Plan 专属 API Key（sk-sp-xxxxx）仅用于在 AI 工具中调用模型抵扣套餐 Credit，不用于 Harness 服务。

**Q：Harness 调用会消耗 Token Plan 的 Credit 吗？**
A：不会。附赠 Harness 权益仅面向以 MCP / 应用服务形式独立调用的 Harness 能力（联网搜索、图像生成、代码解释器、RAG、Memory、Managed Agent、Sandbox 等），与模型调用时通过 Response API 附带的内置工具（走 Credit 抵扣）分列两条口径。Harness 权益与套餐 Credit 独立核算——调用只扣自身权益次数/额度，超出部分按对应服务的折扣价走按量账单，不占用套餐 Credit，也不占用加量包。

**Q：套餐升级后附赠权益如何计算？**
A：升配后按「原套餐剩余次数继承 + 按剩余天数折算新套餐的补差次数」计算，公式为 ((原套餐总次数 - 已用次数) + (新套餐总次数 - 原套餐总次数) × 剩余天数 / 30) 向上取整。示例：Standard 升配到 Pro，联网搜索权益 Standard 100 次已使用 20 次、Pro 500 次，套餐剩余 10 天，则升配后可用次数 = (100 - 20) + (500 - 100) × 10 / 30 向上取整 = 214 次。

**Q：如何查看附赠 Harness 权益的剩余量？**
A：在「我的订阅」页面可以查看每项附赠权益的剩余次数或剩余额度，以及权益到期时间。

**Q：加量包能否用于抵扣 Harness 服务的费用？**
A：不能。加量包仅用于补充 Token Plan 套餐的模型 Credit 额度，Harness 附赠权益独立核算，超出权益部分按对应服务的折扣价走按量账单，不占用加量包。
