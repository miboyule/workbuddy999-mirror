# 隐私政策

发布日期：【2026 年 08 月 24 日】  
生效日期：【2026 年 08 月 24 日】

【运营主体全称】（以下简称“我们”）重视您的隐私。本政策说明我们在运营本平台网站、控制台、API 网关、模型调用、账户充值、订阅及其他相关服务时，如何处理和保护个人信息。

我们遵循目的明确、最小必要、公开透明和安全保护原则。**对于普通同步 API 转发，我们不以业务数据库、消费日志或分析系统持久化保存您的请求正文和响应正文；请求内容仅为完成路由、格式转换、上游调用和结果返回而进行瞬时处理。**我们仅有限保存账户与联系信息、账户凭证、每次调用的 Token 用量和消费明细，以及保障服务安全、结算和合规所必要的信息。

**我们不会将已保存的用户信息用于对外营销或广告，不出售用户个人信息，也不会为与本服务无关的目的向第三方提供用户信息。**但为完成您主动发起的模型调用、支付、登录验证、消息通知、基础设施托管或履行法定义务，相关服务商可能处理完成该目的所必要的信息。具体情况见本政策第四部分。

## 一、我们如何处理请求输入与输出

### 1. 普通同步 API 请求

对于聊天、文本生成、嵌入、语音、图片等以同步或流式方式即时返回结果的 API 请求：

1. 我们会在服务器内存中临时解析和处理输入，并将其转发至实际提供模型能力的上游服务商；
2. 我们会接收上游响应并即时返回给您；
3. 我们不将请求正文、提示词、对话内容、上传文件正文或模型响应正文写入业务数据库、消费日志或用于用户画像、模型训练、广告和对外营销；
4. 请求处理完成后，平台不以内容副本形式继续保留上述输入和输出；
5. 我们可能对请求进行不保留正文的实时安全校验、格式转换、Token 估算和路由处理。

### 2. 异步媒体与任务型服务

**重要提示：如果平台启用了异步绘图、Midjourney、视频、音乐或其他需要提交后轮询结果的任务功能，为关联任务状态和向您交付结果，系统可能保存任务提示词或输入摘要、任务标识、任务响应数据、生成结果 URL、进度和失败原因。此类信息不属于“普通同步 API 零内容留存”的范围。**

我们仅在实现异步任务、展示历史记录、结算和排障所必要的范围内处理上述信息，不将其用于训练、广告、对外营销或无关第三方用途。异步任务内容的保存期限为【请按实际部署填写，例如：任务完成后 7 日/30 日】；期限届满后删除或匿名化，但法律另有规定或争议处理确有必要的除外。

如运营方希望实行“任何请求输入与输出均不保留”的严格政策，应关闭异步任务及任务历史功能，或在发布本政策前完成相应的无内容持久化改造。

### 3. 上游服务商的处理

本平台是 API 网关。为完成您的请求，我们必须将必要输入传输给您选择或系统路由的上游模型服务商，并接收其输出。上游服务商可能依据其自身条款、隐私政策、企业数据政策和地域规则处理或保存相关内容。我们不会授权上游服务商将您的数据用于与本次服务无关的营销或广告，但其独立处理行为仍受其自身规则约束。

请勿在请求中提交完成任务所非必需的身份证件、账户密码、支付口令、健康信息、生物识别信息、未公开商业秘密或其他高度敏感信息。您应在使用具体模型前了解相应上游服务商的隐私规则。

## 二、我们处理的信息及用途

我们只处理提供、结算、保护和维护本服务所必要的信息。

### 1. 账户与基本联系信息

可能包括：

- 用户名、显示名称、电子邮箱、手机号码；
- 注册时间、最后登录时间、账户状态、用户分组和账户备注；
- 您选择第三方登录时的 GitHub、Discord、OIDC、微信、Telegram、Linux DO 等账户标识；
- 邀请关系、代理或账户类型等账户管理信息；
- 您设置的通知邮箱及客服沟通中主动提供的信息。

用途：创建和管理账户、身份验证、找回账户、发送必要的服务通知、提供客服支持、防止欺诈和履行法定义务。

### 2. 用户凭证与安全信息

可能包括：

- 经单向加密散列处理的密码；
- 平台 API Key、访问令牌及其名称、权限范围、额度、有效期、状态、IP 白名单和最近访问时间；
- 通行密钥的凭证标识、公钥、认证器信息及使用时间；
- 多因素认证或第三方登录绑定信息；
- 您主动配置的 Webhook 密钥、Gotify Token 等通知凭证。

用途：账户登录、请求鉴权、权限控制、额度管理、安全验证和按您的配置发送通知。您应妥善保管所有凭证并及时撤销已泄露凭证。

### 3. 每次请求的用量与消费明细

可能包括：

- 请求时间、模型名称、令牌名称或标识、用户分组、渠道标识；
- 输入 Token 数、输出 Token 数、缓存 Token 数，以及文本、图片、音频、推理等分类 Token 数据；
- 消费额度、模型价格或倍率、预扣、补扣、退款、调用次数、请求耗时、是否流式及任务状态；
- 平台请求 ID、上游请求 ID、错误类型和必要的诊断信息；
- 在您主动开启“记录 IP 日志”功能时，与调用日志关联的 IP 地址。

这些记录不以请求正文或响应正文为内容。我们使用它们进行计费、余额与订阅结算、展示消费记录、处理退款和争议、容量与稳定性分析、故障排查及防止滥用。

请注意，上游错误消息或异步任务失败原因可能含有由上游返回的有限诊断文本。我们将避免在诊断信息中主动记录您的完整请求内容；如您发现日志意外包含敏感信息，请联系我们处理。

### 4. 充值、订单与订阅信息

可能包括：订单号或交易号、支付方式和支付服务商、金额、额度、创建及完成时间、订单状态、订阅套餐、有效期、兑换记录、退款及对账信息。

我们通常不直接保存完整银行卡号或支付密码；此类支付凭证由实际支付服务商处理。我们保存必要的交易记录用于完成充值、订阅、开票或对账、处理退款和履行财税义务。

### 5. 设备、网络与运行安全信息

可能包括：登录或访问时间、IP 地址、浏览器和设备的基础信息、会话标识、Cookie、本地存储的偏好设置、请求 ID、异常事件及安全审计记录。

用途：维持登录状态、保存界面偏好、排查故障、防止攻击、欺诈、凭证滥用和保障服务安全。前端游乐场或聊天功能可能将内容保存在您的浏览器本地存储中；该本地数据由您使用的设备和浏览器控制，并不因此上传至我们的业务数据库。

### 6. 客服与反馈信息

当您联系我们时，我们会处理您主动提供的联系方式、问题描述、相关请求 ID、订单号和往来记录，用于核验身份和解决问题。请勿在客服材料中提供不必要的请求正文、响应正文或敏感凭证。

## 三、处理依据

我们根据适用法律，在下列基础上处理个人信息：

1. 为订立、履行您作为一方当事人的合同所必需，例如创建账户、请求鉴权、模型转发、计费和交付结果；
2. 取得您的同意，例如可选的第三方登录、通知方式或 IP 日志记录；
3. 履行法定义务，例如网络安全、会计税务、反欺诈和监管要求；
4. 在紧急情况下保护自然人的生命健康和财产安全；
5. 法律法规规定的其他处理基础。

您可拒绝提供非必需信息或撤回相应同意。对提供核心服务所必需的信息，如您拒绝提供，我们可能无法提供对应功能。

## 四、委托处理、共享与第三方服务

我们不出售您的个人信息，也不为第三方营销或广告目的共享个人信息。仅在以下必要场景中，相关接收方可能处理有限信息：

1. **上游模型服务商**：接收完成模型调用所必需的请求输入、参数和技术标识，并返回输出与用量数据；
2. **云与基础设施服务商**：提供服务器、网络、数据库、缓存、存储、内容分发、安全防护和监控服务；
3. **支付服务商**：处理充值、订阅、退款和对账所必需的订单、金额和账户信息；
4. **身份验证服务商**：在您选择 OAuth、短信、邮件、通行密钥或人机验证功能时，处理登录和验证所必需的信息；
5. **通知服务商**：在您启用邮件、短信、Webhook、Bark、Gotify 等通知功能时，按您的配置发送必要的通知内容；
6. **专业顾问、审计或监管机构**：仅在法律要求、争议处理或保护合法权益所必要的范围内提供信息。

我们会要求受托服务商按照约定目的、期限、方式和安全措施处理信息，不得将信息用于其自身的无关营销或广告目的。具体启用的服务商及其联系方式或隐私政策应由运营方在上线前通过【第三方服务商清单链接】公开并及时更新。

除上述情形外，未经您的单独同意，我们不会向其他个人信息处理者提供您的个人信息，但法律法规另有规定的除外。发生合并、分立、解散、被宣告破产等导致个人信息转移的，我们将依法告知接收方信息，并要求其继续受本政策约束；处理目的或方式变化的，接收方应依法重新取得同意。

## 五、跨境处理

部分上游模型或基础设施服务商可能位于中华人民共和国境外。只有在实际服务涉及跨境提供个人信息时，我们才会按照适用法律履行告知、取得单独同意、个人信息保护影响评估及适用的数据出境程序，并在【第三方服务商清单链接】披露境外接收方、处理目的、信息种类和权利行使方式。

如运营方尚未完成适用的跨境合规程序，应仅启用符合部署地法律要求的服务商和数据区域。

## 六、保存期限

我们仅在实现处理目的所必要的最短时间内保存个人信息，并按以下规则确定期限：

1. **普通同步请求输入与输出**：平台不持久化保存；仅在完成本次请求所需的内存处理期间存在；
2. **异步任务输入、任务数据及结果 URL**：保存【实际期限】；任务功能关闭时不处理此类信息；
3. **账户与联系信息、用户凭证**：在账户存续和提供服务所必要期间保存；账户注销后在【实际删除或匿名化期限】内处理，但依法需要保留的除外；
4. **Token 用量、消费、充值、订单和订阅记录**：在账户存续期间及其后【实际期限】保存，以满足对账、审计、财税、争议处理和法定义务；
5. **登录、安全与运行日志**：保存【实际期限；如适用，至少满足法定网络日志期限】；
6. **客服与投诉记录**：在问题处理完毕后保存【实际期限】。

期限届满后，我们将删除或匿名化相关信息；因诉讼、投诉、审计、安全事件或法律要求需要继续保存的，我们会限制其处理范围，不再用于原处理目的之外的用途。

## 七、我们如何保护信息

我们采取与信息性质和风险相适应的措施，包括访问控制、身份验证、密码散列、权限隔离、日志审计、传输安全、备份恢复、漏洞修复和安全事件响应等。我们限制只有履行职责所必要的人员访问用户信息，并要求其承担保密义务。

请理解，任何互联网传输和存储方式都无法保证绝对安全。如发生可能对您的权益造成影响的个人信息安全事件，我们将依法采取补救措施，并按规定告知事件情况、可能影响、已采取或拟采取的措施、您的防范建议及联系方式；法律要求时，我们也会向有关主管部门报告。

## 八、您的权利

在适用法律规定的范围内，您有权：

1. 查阅、复制您的个人信息；
2. 更正、补充不准确或不完整的信息；
3. 删除符合法定删除条件的信息或申请注销账户；
4. 撤回基于同意的处理授权，但撤回不影响撤回前处理活动的合法性；
5. 限制或拒绝特定处理，并要求我们解释个人信息处理规则；
6. 获取注销后的处理说明，或依法要求将个人信息转移至指定处理者；
7. 对我们的处理行为提出投诉、举报或依法寻求救济。

您可通过账户设置或本政策“联系我们”所列方式提交请求。为保护账户安全，我们可能要求您核验身份。我们将在适用法律规定的期限内答复；对明显不合理、重复或超出法律要求的请求，我们可能依法说明理由或收取合理成本。

账户注销并不当然删除法律要求保留的交易、计费和安全记录，也不会删除已经由上游服务商依据其独立规则处理的信息。我们会对继续保存的信息限制处理，并在期限届满后删除或匿名化。

## 九、未成年人

本服务主要面向具备完全民事行为能力的用户。未满十八周岁的用户应在监护人指导下使用；如涉及不满十四周岁未成年人的个人信息，我们将依法取得监护人同意并采取专门保护措施。若我们发现未依法取得授权而处理了未成年人信息，将在核实后尽快删除或采取其他适当措施。

## 十、政策更新

我们可因法律变化、服务调整或处理活动变化更新本政策。发生处理目的、处理方式、信息种类、保存期限、接收方等重大变化时，我们将通过显著页面提示、站内通知、邮件或其他合理方式告知您，并在法律要求时重新取得同意。

更新后的政策自载明日期生效。我们会保留历史版本，便于您查阅。
