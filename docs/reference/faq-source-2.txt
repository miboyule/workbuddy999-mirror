# 七牛云 AI 大模型企业订阅 FAQ
> 来源：[https://developer.qiniu.com/aitokenapi/13330/subscription-introduction](https://developer.qiniu.com/aitokenapi/13330/subscription-introduction)
> 副标题：快速了解 AI 大模型企业订阅的规则、限制与使用方式

**01 Q：模型积分是如何结算的？**
A：
**基本倍率**
积分以 0.004 元/K tokens 为基准单价，每 1K 积分对应 1K tokens 的基准用量。不同模型按刊例价折算出价格系数（= 模型刊例价 ÷ 0.004），实际消耗积分 = 用量（K tokens）× 价格系数。

**额外倍率**
部分新上线或资源紧张的模型会在基本倍率之上叠加额外倍率，最终消耗积分 = 用量（K tokens）× 基本倍率 × 额外倍率。额外倍率会在模型详情页标注，并在资源充足后适时取消。

**计算示例**
以 GLM 5.1 为例（输入刊例价 0.006 元/K，基本倍率 = 1.5，暂无额外倍率）：
- 每 1K 输入 tokens 消耗 1.5K 积分
- 若订阅含 50 亿积分，可换算约 33 亿输入 tokens（50 亿 ÷ 1.5），按刊例价折算约价值 2 万元

倍率越高的模型消耗越快，建议结合主要使用的模型估算所需积分量。

**02 Q：我可以同时购买多个订阅吗？**
A：单个团队账号当前仅支持同时拥有一条生效中的订阅。不同产品线的方案不可叠加购买（避免模型权益重复）。在同一产品线内仅支持升级至更高档位，不支持在生效周期内降级。

**03 Q：订阅内的模型是否会随时变动？**
A：订阅内模型会根据市场与技术动态适时优化，重大调整将提前通知，保障用户体验连续性。

**04 Q：如果团队额度用完了怎么办？**
A：
- 周期额度用完：耐心等待下一个刷新周期，额度将自动恢复
- 全部额度用完：通过按量付费模式的 API Key 继续使用服务，或升级至更高等级的订阅计划

**05 Q：API 访问权限如何保障安全？**
A：订阅仅能通过订阅 API Key 访问，可以前往【API Key 管理】页面管理你的订阅访问。
链接：[https://portal.qiniu.com/ai-inference/api-key](https://portal.qiniu.com/ai-inference/api-key)

**06 Q：可以随时升级或取消计划吗？**
A：
- 升级：升级后权益立即生效
- 取消：通过取消续订方式生效，当前订阅周期内服务不变，到期后自动终止
- 目前暂不支持降级

**07 Q：订阅的积分额度没用完会不会过期？**
A：所有订阅计划的额度遵循“订阅周期清零”规则，不累计至下一周期。
订阅周期分别为：包月 30 天、包季 90 天、包年 365 天。请合理规划用量。

**08 Q："每周刷新额度"具体是什么意思？**
A：系统每周为您补充一次可用额度。如果在当前周期内提前用完额度，需等待下一个刷新周期才能获得新额度。
订阅范围内所有模型共享该限制额度，不单独计算。

**09 Q：升级订阅时费用如何计算？**
A：升级时系统会自动计算当前订阅剩余天数对应的差价，只需支付差额即可。
升级后新计划立即生效，下次续费将按新计划价格扣费。

**10 Q：我该如何选择订阅计划？**
A：建议综合以下因素评估所需额度：
- 团队规模与月均调用量
- 主要使用场景（如代码开发、内容生成、智能问答等）
- 主要使用的模型及其积分系数

如果仍难以决定，欢迎随时联系我们的客服获取个性化建议。

**11 Q：我可以在购买之后退款吗？**
A：用户通过购买本订阅以及自动续费完成的扣款，除法律法规另有规定、支付渠道另有规则或本平台另有明确承诺外，已生效周期的服务费用不予退还。
