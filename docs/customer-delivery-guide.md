# WorkBuddy 兑换码使用说明

## 1. 登录
打开 https://www.workbuddy999.top，选择“兑换码”，输入完整兑换码并同意协议。兑换码首次登录或首次连接接口时激活，套餐有效期为 30 天。

## 2. 获取 API Key
登录后进入“API 密钥”，激活套餐后点击“显示并复制完整密钥”。接口地址使用 https://api.workbuddy999.top/v1。

## 3. 客户端配置
在 WorkBuddy、CodeBuddy、TraeWork、ZCode 或扣子中选择自定义 OpenAI 兼容接口，填入接口地址、API Key 和模型 ID。模型列表可在“模型中心”查看。

## 4. 充值与续费
兑换新套餐后会继续绑定当前会员账户。账户、会员名和 API Key 登录均可使用；套餐到期后重新兑换即可。
