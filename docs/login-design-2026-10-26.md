# 会员登录规划与验证

登录页现在统一显示“会员登录”，提供三种入口：

1. **兑换码**：首次登录或首次连接接口时激活套餐并进入关联会员账户。勾选“记住此兑换码（仅本机）”后，兑换码写入当前浏览器本地存储，登录页下次自动填充；“清除”会立即删除。此功能只适合本人设备，协议和隐私政策已明确说明。
2. **会员名**：会员首次用兑换码登录后，在右上角“账户信息”中设置3-32位会员名和8-128位密码。会员名与该兑换码创建的同一个 NewAPI 会员账户关联，之后可使用会员名+密码登录；兑换码登录仍保留，不会被会员名替代。
3. **API 密钥**：使用会员中心生成的密钥登录。后端会检查密钥归属、启用状态、到期时间和剩余额度，任何一项不满足都不能建立会话。密钥不会保存到浏览器本地存储，登录成功后只返回 HttpOnly、SameSite=Lax 会话Cookie。

服务端新增 `portal_accounts.login_name` 与 `login_password_hash` 字段。密码使用 Node.js `scrypt` 加随机盐单向派生，原始密码不写入数据库；会话最长7天。会员名校验和密钥校验均在后端完成，页面校验不是安全边界。

本地验证结果：

- 兑换码登录：200，账户余额和会员资料正常读取。
- 设置会员名与密码：200，回读 `loginName` 正常。
- 会员名+密码登录：200。
- API Key 登录：200；停用、到期或无余额密钥会被拒绝。
- 未勾选用户协议：400。
- 390px 手机布局无横向溢出；刷新、退出后兑换码仍会自动填充；清除按钮能移除记忆值。
- `npm run build` 与现有 `node --test tests/*.test.mjs` 通过。

账号资料入口位于控制台右上角头像 → 账户信息。微信登录/绑定继续保留为预留入口，尚未宣称已接入微信开放平台。
